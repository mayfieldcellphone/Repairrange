# BizHub AI Platform 🚀

A standalone, multi-tenant AI platform that allows business owners to build, train, and deploy purpose-driven WhatsApp/Web bots for any industry.

## 🛠️ Features
- **The "Builder Bot"**: An internal AI that acts as a "Setup Wizard" to implement changes for users.
- **Admin Control Center**: Manage all your subscribers and businesses from a single dashboard.
- **Multi-Tenant Routing**: Support for multiple business profiles (e.g., Mayfield, SelfRepairKit, RepairBill).
- **Live Revenue Tracking**: Integrated with Stripe and Firebase for automatic billing and suspension.
- **Advanced AI Engine**: Powered by Google Gemini 1.5 Pro with RAG (Knowledge Retrieval).

## 🚀 Tech Stack
- **Frontend**: Next.js 14 (App Router)
- **Database/Auth**: Firebase Cloud Firestore
- **Payments**: Stripe Billing Webhooks
- **AI Brain**: Google AI Studio (Gemini API)
- **Hosting**: Vercel

## ⚙️ Setup Instructions
1. **Clone the repo**: `git clone https://github.com/mayfieldcellphone/repairhub-saas-v1`
2. **Install dependencies**: `npm install`
3. **Environment Variables**: Add your `GEMINI_KEY`, `FIREBASE_CONFIG`, and `STRIPE_KEY` to your Vercel settings.
4. **Deploy**: Push to GitHub and link to Vercel.
