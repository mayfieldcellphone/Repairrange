Microsoft Extends Windows 10 Support for Another Year: What Australians Need to Know

RR
By RepairRange Editorial Team • June 26, 2026

Microsoft's Commitment to Windows 10 Users

In a world where tech giants push new software relentlessly, Microsoft has taken a step back, recognising that not every user is ready to make the leap to Windows 11. Despite their best efforts, many Australians are sticking with Windows 10, and Microsoft is listening.

What is the Windows 10 Extended Security Updates Programme?

To address the needs of Windows 10 loyalists, Microsoft launched the Windows 10 Extended Security Updates (ESU) programme last year. This initiative is aimed at users who still rely on the familiar OS and wish to have continued security updates, even as they resist the upgrade urge.

Why Stick with Windows 10?

There are various reasons why many users prefer Windows 10. For some, it’s about familiarity and workflow; others may have compatibility issues with older software or hardware that don’t mesh well with Windows 11. Whatever the cause, it’s clear that there’s a significant segment of the Australian market that values stability over the shiny new features of the latest OS.

How to Enrol in the Extended Security Updates Programme

If you’re signed into your Windows 10 account with a Microsoft account, you automatically qualify for the ESU. However, it’s crucial to keep your system updated regularly to ensure you receive these security updates.

Looking Ahead: Upgrading to Windows 11

While Microsoft is offering support for Windows 10, they will still continue to encourage users toward Windows 11. If you do decide to make the jump, ensure that your hardware meets the new OS requirements, which can sometimes be more stringent than those for Windows 10.

Final Thoughts

Microsoft’s extension of Windows 10 support is a testament to the company’s recognition of user needs. As Australians, being informed about our options allows us to make the best tech decisions that suit our personal and professional lives.
